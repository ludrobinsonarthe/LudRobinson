# **App Name**: eSchool-ISGI Communicator

## Core Features:

- User Role Display: Display the user's role (admin, teacher, student, parent) upon login.
- Announcements Feed: Display school-wide announcements, fetched in reverse chronological order, so newer announcements always appear at the top of the list. Filter and display announcements targeted to the user's role or specific class, for optimal relevance. If attachments are available in the announcement, display them, too.
- Private Messaging: Allow users to send direct messages to other users. Users can view message history in a clean and concise interface.
- AI Message Summarizer: Utilize a tool to automatically summarize lengthy messages, providing a brief overview for quick consumption.
- Profile Management: Allow users to view and update their profile information (e.g., contact details, profile picture).
- Document Access: Provide students with direct access to official school documents (bulletins, certificates, diplomas), and enable the display of links for easy document downloads.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) to convey trust, intelligence, and efficiency. It's modern and pairs well with educational themes.
- Background color: Very light Indigo (#F0F2F9), provides a clean and calm base for content presentation.
- Accent color: Teal (#009688) for interactive elements and highlights, adding a touch of vibrancy and indicating areas needing user action.
- Body text: 'PT Sans', sans-serif, a humanist sans-serif that combines a modern look and a little warmth or personality.
- Headline font: 'Space Grotesk', sans-serif, appropriate for short amounts of text and titles in the announcements.
- Use flat, line-style icons that are intuitive and match the overall clean design.
- Employ a card-based layout for announcements and messages to provide a structured and visually appealing display.
